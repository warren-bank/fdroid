概要:

● デフォルトのネイティブ・セキュリティー・プロバイダーは Android
&nbsp;&nbsp;にバンドルされています
&nbsp;&nbsp;● Android の旧バージョンでは古くなっています
&nbsp;&nbsp;● 例えば、
&nbsp;&nbsp;&nbsp;&nbsp;● Android 4.x は TLS 1.2 をサポートしません。
&nbsp;&nbsp;&nbsp;&nbsp;● TLS 1.2
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;は、「暗号化されている」ルート証明書によって要求されます。

● 「暗号化」はライブラリーです
&nbsp;&nbsp;● 多くの現代の暗号スイートを実装する
&nbsp;&nbsp;● 優先プロバイダーとして Java セキュリティー・モデルに直接接続
