Смаки випусків:

● InternalConscryptSecurityProvider
&nbsp;&nbsp;● Conscrypt включений як внутрішній
&nbsp;&nbsp;&nbsp;&nbsp;бібліотеку
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;https://github.com/google/conscrypt/
&nbsp;&nbsp;● Випуски окремих APK для кожного ABI

● SharedExternalConscryptOrDefaultSecurityProvider
&nbsp;&nbsp;● Conscrypt завантажується з спільного
&nbsp;&nbsp;&nbsp;&nbsp;додатка
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;https://f-droid.org/packages/com.mendhak.conscryptprovider/
&nbsp;&nbsp;● Для того, щоб скористатися типовим
&nbsp;&nbsp;&nbsp;&nbsp;постачальника безпеки, буде
&nbsp;&nbsp;&nbsp;&nbsp;використано типовий постачальник
&nbsp;&nbsp;&nbsp;&nbsp;даних:
&nbsp;&nbsp;&nbsp;&nbsp;● цей додаток недоступний
&nbsp;&nbsp;&nbsp;&nbsp;● цей додаток не підписується з
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;надійним джерелом

Огляд:

● Типовий вбудований провайдер безпеки у
&nbsp;&nbsp;Android
&nbsp;&nbsp;● застаріла у старих версіях Android
&nbsp;&nbsp;● наприклад:
&nbsp;&nbsp;&nbsp;&nbsp;● Android 4.x не підтримує TLS 1.2
&nbsp;&nbsp;&nbsp;&nbsp;● TLS 1.2 потрібен для кореневого
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;сертифіката "Let's Encrypt"

● Conscrypt-це бібліотека
&nbsp;&nbsp;● реалізовує багато сучасних підів
&nbsp;&nbsp;&nbsp;&nbsp;шифрів
&nbsp;&nbsp;● plugin безпосередньо до моделі Java
&nbsp;&nbsp;&nbsp;&nbsp;Security як бажаного постачальника
