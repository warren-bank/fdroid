Overview:

● the default native Security Provider
&nbsp;&nbsp;is bundled in Android
&nbsp;&nbsp;● is outdated in old versions of
&nbsp;&nbsp;&nbsp;&nbsp;Android
&nbsp;&nbsp;● for example:
&nbsp;&nbsp;&nbsp;&nbsp;● Android 4.x does not support TLS
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;1.2
&nbsp;&nbsp;&nbsp;&nbsp;● TLS 1.2 is required by the "Let's
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Encrypt" root certificate

● Conscrypt is a library
&nbsp;&nbsp;● implements many modern cipher suites
&nbsp;&nbsp;● plugs directly into the Java
&nbsp;&nbsp;&nbsp;&nbsp;Security model as the preferred
&nbsp;&nbsp;&nbsp;&nbsp;Provider
